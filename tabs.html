Problem

Analytics showed 9% of our 5 million users (450,000 people) managed 30+ tabs simultaneously in a flat list with no organization. These power users drove our referral program and had the highest engagement - they were our growth engine.

User Feedback

Users complaining that tabs are inconvenient to use

Users asking for features like tab grid and grouping

Business Concerns

Functionality gap to competitors

Losing retention opportunities

Design Concerns

Outdated UX patterns

Outdated UI

Solution

Built initial prototypes to validate grouping as the top user need. Aligned goals and strategy with product and engineering teams, created a feature roadmap prioritizing iOS for complete implementation.

Initial Release

Initial release used square tab previews. User feedback revealed rectangular tabs showed more page content, making tabs more scannable. We shipped this update along with improvements to private mode switching.
